# Diabetes Disease Prediction using Machine Learning

## Project Overview
This project predicts whether a person is likely to have diabetes based on medical data using Machine Learning techniques.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Google Colab

## Machine Learning Algorithm
- Random Forest Classifier

## Features
- Dataset loading and preprocessing
- Model training and testing
- Diabetes prediction system
- Accuracy evaluation

## Model Accuracy
- Achieved approximately 76% accuracy.

## Dataset
Pima Indians Diabetes Dataset
